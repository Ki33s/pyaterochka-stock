# Учёт товаров магазина — v1.0.0

Веб-приложение для учёта товаров с примерным ассортиментом «Пятёрочки».

[Открыть приложение](https://pyaterochka-stock-ki33.justlime.chatgpt.site)

## Возможности

Каталог и цены, остатки в штуках и килограммах, поступления, продажи, списания, инвентаризация, журнал операций, поиск и фильтры, отчёт по категориям, экспорт CSV и резервные копии JSON. Продажа и списание сверх остатка блокируются.

Данные сохраняются в браузере. Для переноса учёта используйте «Сохранить резервную копию» и «Загрузить резервную копию». Цены и ассортимент примерные; подключения к 1С и внутренним системам торговой сети нет.

## Запуск

Откройте `uchet-tovarov.html` в браузере — это самостоятельная страница со встроенными CSS и JavaScript.

Для разработки доступны `index.html`, `style.css`, `app.js`. Можно запустить статический сервер: `python -m http.server 8000`, затем открыть `http://localhost:8000`.
