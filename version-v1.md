# Учёт товаров — версия 1.0.0

Сохранена 10 октября 2026 года, перед будущей версией в духе Papers, Please.

- Приложение: https://pyaterochka-stock-ki33.justlime.chatgpt.site
- Git-коммит: `e69d42ed4a12bbc84fe24658a09fc54e3fcfcfbe`.
- Метка Git: `v1.0.0`.
- Версия Sites: `appgprj_6aca7593b1588191869bfa52d734f258~appgver_2b99994fe764819194626b1398d85f6d`.
- Архив исходников: `pyaterochka-v1-source.zip`.
- Git с историей и меткой версии: `pyaterochka-v1.git.bundle`.
- Самостоятельная страница: `uchet-tovarov.html` — открыть обычным браузером.

Функции v1: каталог и цены, остатки в штуках и килограммах, поступление, продажа, списание, инвентаризация, журнал, поиск и фильтры, отчёт по категориям, экспорт CSV и резервные копии JSON. Данные учёта сохраняются в браузере.

Снимок исходников содержит примерный ассортимент. Ваши изменения каталога и операции из браузера не входят в этот архив: для них нажмите в приложении «Сохранить резервную копию».

Будущая версия: пользователь попросил сделать её как Papers, Please. Эта идея сохранена; оформление и механику предстоит уточнить при следующей работе. Изменения v2 пока не выполнялись.

Для восстановления репозитория: `git clone pyaterochka-v1.git.bundle pyaterochka-v1`, затем `git checkout v1.0.0`.
